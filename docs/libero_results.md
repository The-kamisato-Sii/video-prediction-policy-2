# LIBERO-Pro 实验结果

更新于 2026-11-25。收录本分支 50 个完成五类扰动评测的 30k checkpoint。闭环成功率统一写作 **SR800 / SR2000（%）**。完整的 2,000 次评测包含前述 800 次。每个模型的各扰动成功数、分母和训练运行标识可在[闭环结果 CSV](results/libero_pro.csv)中查阅。

## 主要发现

- **动作标签最少时，加入仿真 Flow 的收益最大。** 固定 32 tokens 和 10 步 Action FM，1/8 Action 的 SR2000 从 56.60% 升到 65.55%（1,132 → 1,311 次成功，+8.95 个百分点）。相同评测样本里，加入 Flow 后从失败转为成功的有 245 条，从成功转为失败的有 66 条。1/4、1/2 和全部 Action 时，相对各自纯 Action baseline 的增幅依次为 4.25、2.80 和 1.50 个百分点。
- **214 条带动作标签的轨迹，加上 1,589 条轨迹的 GT Flow，在这次评测中达到了全量纯 Action 的水平。** 两者在 800 条上分别为 47.00% 和 43.88%，在 2,000 条上分别为 65.55% 和 64.95%。后一个差距只有 12 次净成功，配对结果为 149 条转好、137 条转差。这个结果支持减少动作标注的假设。精确的可替代比例还需要独立训练种子和更多标注比例验证。
- **单步 Action 下，Flow 的监督方式会改变两套评测的排序。** 1/8 Action、32 tokens 的 Adaptive MeanFlow 在两侧均做 MeanFlow 时得到 46.50% / 63.25%，把 Flow 换成卷积重建后得到 44.00% / 65.25%。后者在 Position + Task 上少成功 20 条，在 Object、Language、Environment 上分别多成功 31、14、15 条，合计净增 40 条。只看 800 条会对这两个方法作出相反选择。
- **更复杂的重建头尚未提高五轴闭环成绩。** 三种独立 DPT 的 SR2000 为 63.60%–63.80%，同配置卷积为 65.25%。独立 DPT 加深度后，全图场景流 EPE 略低于卷积（0.604 对 0.624 mm），但运动像素 EPE 更高（4.42 对 3.50 mm）。评估操作相关的运动精度时，全图均值会掩盖这一区别。

## 评测与训练口径

| 项目 | 设置 |
| --- | --- |
| SR800 | 每类扰动覆盖 Spatial、Object、Goal、Long（LIBERO-10）四个 suite，共 40 个任务，每任务 10 次。Position（`swap`）与 Task 各 400 次 |
| SR2000 | 上述 800 次，加 Object、Language、Environment 各 400 次。每个扰动在总分中权重均为 20%。Environment 沿用协议内的 50 次原环境对照 |
| 推理 | 策略 seed 42，视频 seed 43，仿真 trial seed 和初态索引均为 1–10。重置后等待 15 步，预测 32 个 Action，执行 10 个后重新规划 |
| 训练预算 | Video-10k，Action 或共享 DiT 训练 30,000 步，全局 batch 256。分数取最终 checkpoint。NFE 表示 Action 预测的模型求值次数 |
| Action 子集 | 以完整 episode 为单位、按任务分层，seed 42 生成嵌套清单。1/8、1/4、1/2、全部分别为 214、428、856、1,712 条 |
| Flow 标签 | 主视角点图 + 三维场景流，源帧偏移为 0、4、…、28，位移间隔为 4 步。GT 和 4RC 的受控比较共用 1,589 条可用 episode。Action 子集与 Flow 集可以重叠。常规共享 DiT 按 batch 切换 Action 与 Flow 监督，Prefix 的 Action batch 另加重建监督 |

以下为本分支在固定评测种子下的实测结果。百分比按成功数计算后四舍五入至两位，小差值应结合试验数和训练种子解读。表中“—”表示该组合缺少完整可比结果或对应输出头。VPP2 发布权重的原始 LIBERO、OOD 与 PRO 参考成绩另见[发布版基准表](libero.md#1-reference-results)。[本地 PRO 协议](libero_pro_local_eval.md) · [4RC 与 GT 训练对照](libero_pseudo_flow.md) · [任务采样规则](../scripts/libero_flow/SAMPLING.md)

## 1. Flow 能替代多少动作标注？

各行的 Action 均用 10 步 FM。GT 来自仿真 replay，4RC 来自主视角视频估计。Flow FM 在预训练 MotionVAE latent 上去噪，卷积重建使用可学习 query，直接监督点图和场景流。

| 方法 | Tokens | 1/8 Action | 1/4 Action | 1/2 Action | 全部 Action |
| --- | ---: | ---: | ---: | ---: | ---: |
| 纯 Action FM | 32 | 33.38 / 56.60 | 38.75 / 62.10 | 42.25 / 64.00 | 43.88 / 64.95 |
| Action FM + GT Flow FM | 32 | 47.00 / 65.55 | 44.88 / 66.35 | 46.25 / 66.80 | 47.38 / 66.45 |
| Action FM + GT Flow FM | 64 | 46.25 / 64.70 | 45.25 / 64.90 | 44.25 / 66.90 | 45.00 / 67.40 |
| Action FM + GT Flow FM | 128 | 44.88 / 64.00 | 45.75 / 65.90 | 45.25 / 66.00 | 47.13 / 67.70 |
| Action FM + GT Flow 卷积重建 | 32 | 43.75 / 63.15 | 43.38 / 64.05 | 43.88 / 64.05 | — |
| Action FM + GT Flow 卷积重建 | 128 | 43.25 / 62.95 | — | — | — |
| Action FM + 4RC Flow FM | 32 | 43.88 / 64.30 | 48.25 / 67.45 | 47.63 / 66.50 | — |

在 1/8 Action 时，GT Flow FM 的 32 tokens 在两个评测口径上均领先于 64 和 128 tokens。全部 Action 时，128 tokens 的五轴总分最高（67.70%），32 tokens 的双轴分更高（47.38%）。4RC 在 1/8、1/4、1/2 Action 下的五轴成绩都超过各自的纯 Action baseline。相对同配置 GT Flow，三档差值分别为 −1.25、+1.10、−0.30 个百分点。

在同一组 1/8 Action、32 tokens、10 步 Action FM 模型中，把 GT Flow FM 换成卷积重建，训练轨迹上的运动像素 EPE 从 **17.53 降到 3.18 mm**，五轴闭环成功率却从 **65.55% 降到 63.15%**。前者衡量一次固定采样与演示中实际位移的误差，后者衡量策略完成任务的能力。只按训练轨迹的几何误差选模型，会选中这组里闭环成功率较低的模型。[几何测量值](results/libero_geometry.csv)

## 2. 单步 Action 的 Flow 监督与 Prefix 消融

本表固定 1/8 Action、全量可用 GT Flow 和 32 tokens。Prefix 在 Action batch 也用对应的 Flow 监督前缀 query，Action token 可以读取前缀状态。iMF Boundary 用边界速度估计，iMF Auxiliary 用额外速度头。

| Action 方法 | Flow 同样做单步去噪 | Flow 卷积重建 | Flow 卷积重建 + Prefix |
| --- | ---: | ---: | ---: |
| Adaptive MeanFlow | 46.50 / 63.25 | 44.00 / 65.25 | 44.25 / 64.10 |
| Adaptive + 独立对角采样 | 44.25 / 62.40 | 39.50 / 60.20 | 43.38 / 63.60 |
| iMF Boundary | 44.00 / 61.80 | 43.25 / 63.20 | 45.88 / 62.80 |
| iMF Auxiliary | 43.75 / 63.45 | 43.25 / 64.00 | 28.75 / 41.85 |

在 Adaptive 和两种 iMF 配置下，非 Prefix 卷积重建的 SR2000 都高于双侧去噪。独立对角采样时，卷积重建低 2.20 个百分点。Prefix 的收益也依赖配置，尤其是 Auxiliary 从 64.00% 降至 41.85%。这个 Prefix checkpoint 曾从 15k 续训到 30k。作为 10 步对照，Action FM + 卷积重建加入 Prefix 后为 **42.38 / 63.00**，原卷积重建为 **43.75 / 63.15**。

| 仅 Action，全部动作标签 | Action 去噪或回归次数 | SR800 / SR2000（%） |
| --- | ---: | ---: |
| FM | 10 | 43.88 / 64.95 |
| 直接回归 · MSE | 1 | 38.63 / 63.30 |
| 可学习 query 回归 · MSE | 1 | 40.13 / 62.80 |
| Adaptive MeanFlow | 1 | 44.25 / 65.75 |

Adaptive MeanFlow 用一次 Action 求值得到 65.75% 的五轴成功率，10 步 FM 为 64.95%，差 16 次成功。这里记录的是求值次数，端到端延迟还受视频条件编码和部署方式影响。

## 4. 卷积、DPT 和几何精度

固定 1/8 Action、32 tokens 和一步 Adaptive Action MeanFlow。几何评测在 1,589 条成功 replay 的**训练轨迹**上每条抽取一个固定 clip，四套 suite 共用相同的抽样规则。点图与场景流的三维端点误差（EPE）按各自有效像素计算。运动像素定义为 GT 位移大于 1 mm。闭环成功率来自另一套 LIBERO-Pro 扰动轨迹。[40 个 checkpoint 的几何指标 CSV](results/libero_geometry.csv)

| 重建头 / 监督 | SR800 / SR2000（%） | 点图 EPE ↓（mm） | 运动像素场景流 EPE ↓（mm） | 独立深度输出 RMSE ↓（mm） |
| --- | ---: | ---: | ---: | ---: |
| 卷积 · 点图 + 场景流 | 44.00 / 65.25 | 10.38 | 3.50 | — |
| 共享 DPT · 点图 + 场景流 | 44.50 / 63.45 | 14.82 | 5.80 | — |
| 共享 DPT · 场景流损失权重从 100 调到 1,000 | 39.38 / 60.55 | 16.18 | 3.71 | — |
| 共享 DPT · 加深度 | 44.25 / 63.95 | 15.86 | 6.89 | 52.38 |
| 共享 DPT · 点图与场景流加置信度 | 42.63 / 63.15 | 22.65 | 5.32 | — |
| 共享 DPT · 加深度与 Prefix | 40.75 / 62.90 | 16.82 | 7.19 | 55.44 |
| 独立 DPT · 点图、场景流各一套 | 44.38 / 63.70 | 14.50 | 4.76 | — |
| 独立 DPT · 点图、场景流、深度各一套 | 45.00 / 63.80 | 13.08 | 4.42 | 52.00 |
| 独立 DPT · 三个模态各带置信度 | 44.63 / 63.60 | 14.19 | 4.95 | 57.90 |

单独增加深度监督时，独立 DPT 的点图 EPE 从 14.50 降到 13.08 mm，SR2000 从 63.70% 到 63.80%，只多成功 2 次。进一步给三种模态都加置信度，深度头 RMSE 从 52.00 升到 57.90 mm。现有数据可以比较各头的几何误差与闭环表现。要解释某种扰动下的动作失败，还需要在该扰动轨迹上测量几何误差。

## 数据来源与核对

闭环 CSV 每行对应一个模型，五个 `*_successes` 扰动列的分母分别为 400。前两列扰动成功数相加得到 SR800 的分子，五列相加得到 SR2000 的分子。按模型、suite、扰动、任务和 episode 核对了 100,000 条模型 rollout。每个模型有 200 个任务与扰动组合，各有 10 条。相同评测在多个队列的中间汇总只计一次。`source_run` 指向项目本地 `runs/` 下的评测目录，`checkpoint_run` 标识训练运行。[闭环计数与运行标识](results/libero_pro.csv)

几何 CSV 的主要来源是 11 月 18–19 日的 30k 几何评测。卷积 Adaptive 与三种独立 DPT 的四行统一取 11 月 23 日同批复测。它们使用相同 clip、mask、阈值与计分程序。空的深度头字段表示没有独立的深度输出。[几何数据与运行标识](results/libero_geometry.csv)
